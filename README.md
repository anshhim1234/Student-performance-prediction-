# Student Dropout Risk Prediction System

An end-to-end ML system to predict student dropout risk using Random Forest, 
Logistic Regression and KNN — achieving 87% accuracy across 1,500+ student records.

## Tech Stack
Python | Scikit-learn | Flask | XGBoost | Pandas | NumPy

## Features
- 3-tier risk prioritization (High/Medium/Low)
- Interactive web dashboard
- Statistical analysis with hypothesis testing and regression
- Real-time risk visualization

## How to Run
pip install -r requirements.txt
python app.py
